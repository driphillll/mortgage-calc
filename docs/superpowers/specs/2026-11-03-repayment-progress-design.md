# 还款进度与主站部署配置

## 需求与边界

- 为后续 CD 保存主站 Nginx 配置，覆盖 HTTP 首次签证、HTTPS 和续期重载。
- 结果区补充已还本金、利息、本息合计，以及待还的相同三项。
- 结果及逐月明细中的金额悬停显示万元，默认仍显示元。
- 保持原生 HTML/CSS/JavaScript、无构建和无运行依赖，不修改线上服务器。

## 实现选择

采用现有还款计划逐期汇总，并提供“已还期数”控制：与银行账单的计期口径一致，也能在未填写开始日期时使用。默认按本地今天及计划还款日期估算；仅有开始年月时按月末判断本期是否结束。期数可在 0 到实际结清期数间手动调整。页面明确这是按计划及期数估算，包含所选期数内的提前还款，而非真实扣款记录。

另一个可行方式是按任意截止日期逐笔拆分，但会额外引入期中、按日统计，与当前按月计息、当月正常还款后应用提前还款的模型不一致，因此本次不采用。是否默认按今天计算已通过异步问题征询；在未收到回复时采用上述建议。

## 计算约定

- 已还本金为已还期数内正常还本加实际生效的提前还款；已还利息为这些期数的利息。
- 待还本金、利息来自剩余期数；两组本息合计分别为本金加利息。
- 金额按分累加，再转换为元；利率调整、超额提前还款和提前结清使用已有计划结果。
- 自动估算只使用完整期数；用户可手动按真实账单修正。
- 金额提示采用浏览器原生 title，格式为两位小数的“万元”。

## 部署约定

`deploy/nginx/default.http.conf`、`default.https.conf` 和 `reload-nginx.sh` 对应现有 HTTPS 文档。域名为 `dclyh.com`，站点资源为 `/data/mortgage-calc/`，域名静态根目录为 `/var/www/html`，ACME webroot 为 `/etc/nginx/letsencrypt`，证书为 `/etc/letsencrypt/live/dclyh.com/`。根路径跳转计算器，不存在的静态资源返回 404。

后续 CD 分别同步网页资源与 Nginx 配置，配置经 `nginx -t` 成功后重载；证书私钥不进仓库。此次仅准备文件和操作说明。
