# 房贷计算器

一个无第三方依赖的单页房贷计算器。支持等额本息、等额本金，贷款期限按年或月输入并自然换算；贷款开始年月和日期可选填；可添加、修改或删除多次利率调整和多笔提前还款，每笔提前还款可选择缩短还款期限或降低月供。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm run serve
```

打开 `http://127.0.0.1:4173`。运行测试：

```bash
npm test
```

在 PowerShell 禁止执行 `npm.ps1` 的环境中，可使用 `npm.cmd run serve` 和 `npm.cmd test`。

## 计算口径

- 使用月利率 `当期年化利率 ÷ 12`，每月利息按未偿本金计算，金额逐月四舍五入到分；末期调整尾差，保证本金结清。
- 首期还款为贷款开始后的次月。只填写开始年月时，明细显示年月；另填日期时，后续月份沿用该日，遇到较短月份则调整为当月最后一天。
- 利率调整需要贷款开始年月。每条记录填写生效年月和调整后**实际执行的年化利率**（已含合同约定加点），从该月计息前生效，并持续到下一次调整。等额本息按当时剩余本金和计划期数重算月供；等额本金维持月还本金规则。开始月的调整适用于首期。相同年月不能重复设置。
- 提前还款归入所选自然月，在当月正常还款后扣减本金；从下月起按所选方式重算。缩短期限时保留当前月供或月还本金，降低月供时保留剩余计划期数。
- 若利率调整和提前还款发生在同月，先按新利率完成当月正常还款，再扣减提前还款。
- 不按实际天数计算利息，也不包含手续费、违约金、自动获取 LPR 报价或银行特殊重定价规则。提前还款金额超过剩余本金时只扣减余额；结清后的计划会提示为未计入。
